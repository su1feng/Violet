# Violet

**一个常驻的个人 agent。它大部分时间在睡觉，醒来的每一次都值得你花时间。**

Violet 是给自己用的：一个在你自己的机器上长期运行、由你已有的 Claude / Codex / Pi 驱动的助手。它会在该醒来的时候醒来——定时、收到消息、事件到达——做完事，然后重新睡回去。

## 它不做什么

- 不是多 bot 社交产品，不做群聊、人格市场
- 不是团队协作平台，不做成员、权限下放、审批链
- 不自己实现 agent loop：模型调用、工具循环、上下文压缩全部交给现成的 CLI
- 不做云端、不做账号体系、不做计费

## 核心设计

| 决定 | 内容 |
| --- | --- |
| **环路** | 事件收件箱 → worker → run → 发件箱，五个原语 |
| **授权** | 跑之前先判断该不该跑；跑完留下"凭什么"的记录 |
| **执行** | 一轮一个子进程，会话指针存库，崩溃必可恢复 |
| **记忆** | 文件目录，索引常驻，正文按需 |
| **交付** | agent 只写发件箱，发不发由 dispatcher 决定 |
